### DSH 角色养成插件 — 独立开源项目（2026.08，已发布 npm v0.2.0）

为 DSH（DeepSeek Harness）Web 界面开发的角色养成插件：为每个会话绑定可长期养成的 AI 角色，解决 AI 对话"无持续人设、记忆靠上下文硬塞、易丢失"的问题。

- 独立完成产品设计 + 工程实现：Host/Client 双半区插件架构，零依赖纯 JavaScript、无需构建，通过 pnpm add + 配置插入块一键安装
- 设计好感度系统：随对话自然变化、分五阶段（冷淡→客气→熟络→亲密→依赖）、语气随阶段调整，系统级维护、用户无法直接修改（防篡改）
- 设计记忆系统：分区存储（长期事实/用户信息/关系状态/承诺/事件）+ 追加式日志自动归档，避免模型整包重写记忆导致的丢失，跨会话累积
- 优化 token 成本：角色段仅注入根会话、子代理不受影响，数据纯本地存储不上传
- 成果：已发布 npm v0.2.0 + GitHub 开源（MIT），完成 Phase 1-4 功能开发（角色档案、AI 设计助手、好感度养成、记忆系统 v3）
