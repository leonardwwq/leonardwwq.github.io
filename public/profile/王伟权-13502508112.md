### DSH 角色养成插件 — 独立开源开发者工具（2026.08，已发布 npm v0.3.0-beta.1）

作为 DeepSeek Harness 的深度用户，识别 AI 编程工具在长期会话中的核心痛点——角色仅靠固定 Prompt 扮演、不拥有随互动积累的状态。独立设计并开发角色状态闭环系统：让 AI 角色从"一段固定 Prompt"变成"会随互动积累认识、跨会话保留、并实际参与回复生成的长期角色"，完成从需求识别到发布的全流程。

- 设计七层状态闭环：Persona→Event（事件流水，只记录不评价）→Appraisal（角色视角评价）→Intimacy（0~100 关系状态）/Belief（带置信度的用户判断）→回复生成（信念参与）→Belief Consolidation（定期整理：相近信念合并取最高置信度、冲突信念降置信度但不武断删除）
- 区分 Belief 与 Memory 两条独立系统：Belief 是"基于事实形成的判断"（非事实、带置信度，最多 5 条注入回复、当前对话表达优先）；Memory 是"记住发生过的事实"（分区存储 + 追加式日志归档，独立于信念整理）——上下文管理的高阶设计
- 可靠性边界：所有状态更新遵循"LLM 提议 → 代码验证 → 确定性执行"，LLM 永远不能直接修改数据——与 AI Copilot"AI 建议→人工确认→自动执行"同一设计哲学
- 工程实现：Host/Client 双半区插件架构，零运行时依赖（不引入数据库/向量库/Agent 框架），单 JSON 原子写 + 数据版本自动迁移（v1→v6），131 个测试全过（0 失败）
- 优化 token 成本：角色段仅注入根会话、子代理不受影响，数据纯本地存储不上传
- 成果：已发布 npm v0.3.0-beta.1 + GitHub 开源（MIT）
