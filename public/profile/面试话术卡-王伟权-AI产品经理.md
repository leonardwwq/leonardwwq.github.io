# 面试话术卡 — 王伟权（AI Agent 产品经理方向）

> 使用说明：面试前通读一遍，重点背 **加粗** 的框架句。所有话术遵循同一原则：**不贬低过去、不暴露负面情绪、把离开说成主动选择**。

---

## Q1. 为什么离职（离开伙伴云）

**核心：不是"不满意"，是"完成一个完整 0→1 周期后的主动选择"**

> ① 成绩：我在伙伴云完成了两件从 0 到 1——ASA/ASO 平台（5000 万美元预算、1000+ 账户承载量），和 AI Copilot（上线验证：选词效率 +75%、操作量 -87%）。这证明我有能力把 AI 产品从想法做到落地、再到数据验证。
>
> ② 主动回应"为什么才 1 年半"：**一年半对我来说是一个完整的 0→1 周期，任务已经闭环，这个阶段我能贡献的价值已经充分兑现。**
>
> ③ 差距：AI Copilot 目前是公司内部提效工具，公司核心业务是投放平台，AI 不是核心产品线——内部工具的资源投入和影响范围有天然天花板。
>
> ④ 收束：**我的职业规划是把 Agent 产品作为核心产品线来做，从内部工具走向对外产品、做规模化。** 所以我想加入一家 AI 产品就是主营业务的公司。

---

## Q2. 为什么选择我们（下一家公司）

**核心：选 AI 赛道 + 选这家公司作为最优载体 + 宣告长期深耕**

> ① 行业方向：我做 AI Copilot 验证了判断——Agent 是确定性方向。我的心理学研究（人机协同决策）、Agent 工程、产品经验全部指向这一条主线。
>
> ② 公司选择（**面试前填好**）：选择贵司，是因为【查好的 1-2 个具体点：AI 产品线/方向/团队积累】。我希望把 0→1 的经验变成规模化产品的经验。
>
> ③ 岗位契合：这个岗位需要同时理解 Agent 技术实现、用户行为和人机协作——我恰好三样都有：能手写 Agent 循环、有心理学研究背景、有商业化产品落地经验。
>
> ④ 稳定性承诺（**翻盘点**）：我前几段经历跨度较大（金融→营销→投放），那是方向探索期。**现在我的主线已经收敛到 AI 产品——学习、工程、产品都指向同一条线。我选贵司，就是选在 AI 赛道上长期发展，这是我最后一次换赛道，接下来是深耕期。**

## Q3. 为什么每段工作都不超过 2 年？（稳定性总攻）

> "我每一段都完成了从 0 到 1 并交付了结果（平台上线、产品商业化、AI 产品验证）。之前行业跨度大是因为我在探索方向；现在 AI 主线已经确定，过去积累的每一步——金融系统的数据能力、营销平台的商业化能力、投放平台的业务理解——都会在 AI 产品这条线上复用。**这次离开伙伴云不是逃避，而是任务完成后向上走的主动选择。**"

## Q4. 为什么没去清华？（落榜）

**核心：能力证明 + 路径选择**

> "我考的是清华 347，综合排名第 32，当年录取 29 人——差 3 个名额。调剂到央财后发现这个结果和我的职业规划严丝合缝：央财是非全日制，我可以边做 AI 产品边读研，导师方向就是人机协同决策——**白天做的 Agent 产品、晚上研究的东西，是同一件事**。这个路径对我不是妥协，是最优解。"

追问"为什么不二战"：> "二战的代价是一年全职备考+一年不确定。我的目标是『AI × 产品』的应用实践，不是学术本身。央财非全让我工作和研究两条腿同时走。"

## Q6. 你做 Agent 多久？数据是团队反馈？

> "严格算 Agent 经验是 2026.02 至今，半年左右。但我是从 AI 产品架构一路做过来的：2025 年完成平台建设（业务场景和数据基础），2026 年初 Agent 在中国爆发时我判断这是确定方向，主动主导完成 MCP + Agent 循环架构并上线。**整个行业 2026 年才起来，Agent 产品经理普遍经验不超过一年，我的半年里有从架构设计到上线验证的完整闭环，而且能现场演示手写的 Agent 循环。**"
>
> 数据口径：> "MVP 阶段靠投放团队（10+ 名优化师）的使用反馈汇总验证：选词耗时对比、操作步骤减少量，综合下来效率 +75%、操作量 -87%。这是内部工具早期的常见验证方式，我们也在规划接入系统埋点做客观数据采集。"

## Q7. 波波平台为什么关停了？

> "波波是我在尚诚同力主导的商业化产品，上线首年做到上千个付费用户、100 万+ 订阅收入。我 2024 年初离开后，公司业务线整体调整，产品随战略收缩关停（公司本身还在正常运营）。
>
> 复盘有两个明确的商业化认知：一是 to B 数据产品的定价逻辑——千元级年费适合个人订阅，对 B 端客户应该做企业版/席位制分层定价，当时定价没有充分体现数据价值；二是商业化不能只靠订阅一条腿，KA 大客户 + 订阅长尾要并行。**这两个认知我在 ASA/ASO 平台的商业化设计里已经在用。**"

## 附：择业要求清单（选下一家公司的标准）

### 底线要求（一票否决）
- [ ] AI 是公司核心产品线（不是内部工具/附属业务）——问："AI 产品线的战略定位？资源投入？汇报线？"
- [ ] 岗位直接负责 Agent / 大模型应用产品（不是边缘辅助）——问："我负责的具体产品？上一个产出？"
- [ ] 非广告/投放行业（个人偏好）
- [ ] 薪酬：持平起步，期望 +20~30%（带着 1.5 年任职的机会成本，不涨就是亏）
- [ ] 职级不降：产品负责人/高级 PM 级别（带过 4 人和 10+ 人团队，不回执行岗）

### 期望（优选条件，占 2 项以上优先）
- [ ] 有 Agent 落地场景和数据（已上线 AI 产品、真实用户）
- [ ] 有 AI 技术团队积累（工程/算法/大模型背景，面试见技术负责人）
- [ ] 业务在增长（有融资或已盈利）
- [ ] 直属上级是 AI 产品/技术背景
- [ ] 北京办公

### 战略考量（这次必须是"最后一跳"）
- [ ] 选"1→10"的公司（已上线产品做规模化），不再赌"0→1"——履历已连续两个 0→1，缺规模化一环
- [ ] 能待 3 年+ 的土壤：问团队流动率、AI 投入持续性（追热点 vs 长期战略）
- [ ] 入职时间避开 2026.09 开学：9 月后再入职，试用期与硕士第一学期错开

### 反向面试问题（面试结束问对方）
1. "这个岗位的 AI 产品在公司战略里的定位？未来 1-2 年资源投入？"
2. "产品现在到什么阶段了——0→1 还是已上线做规模化？"
3. "团队 AI 工程能力在哪？未来 6-12 个月的产品规划？"
4. "直属上级的背景？团队流动率？"
5. "如果入职，3 个月内我的核心目标是什么？"
