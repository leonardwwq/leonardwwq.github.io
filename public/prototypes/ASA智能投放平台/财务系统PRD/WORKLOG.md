## 8 流程草图

> 「明」= 原型注释明确；「确」= 用户确认；「?」= 待定。

```text
[客户登记]
内部建登记表(名称/48或72h有效期，创建即起算/提交通知)(明/确)
  → 生成外链 → 客户免登录填写，每分钟自动保存(明)
  → 客户提交 → 状态「待审核」，通知归属者(明)
  → 内部审核材料（不走审批）(明)
       ├─ 通过 → 待关联(确) → 关联客户 → 待开户(确) → 关联账户 → 已开户(确)
       └─ 不通过 → 未通过（终止，可删）(确 D-01-01)
  过期 → 已过期、链接禁用(明)

[客户资料审批]  新建 / 信息变更 / 付款主体变更 → 审批(会签)(确)
  审批中：展示当前生效信息(明)；撤回：仅审批中、作废原单(明)；驳回同撤回(确 D-04-01)

[充值]  发起 → 审批 → 通过 → 同一收款单确认收款 → 到账 → 交易明细(明)

[月度账单]
每月2日自动出上月账单(UTC0)(明/确)
  ├─ 预付：期末余额≥0 自动结算；<0 待结算+通知(确)
  └─ 后付：人从账单手动生成结算单(待付款)(确) → 收款确认一次到账 → 账单结清，差额进手续费(确)
  状态「待支付」：?(Q-00-08)

[规则配置]  创建人提交 → 审批 → 通过写入（同起始日覆盖）(确)；某日适用 = 起始日 ≤ 该日中最大的(确)；消耗首日共用(确 D-00-56)
[返点/客情]  每自然月按规则有效期切片计算(确 D-00-55)
  返点 = (消耗 − 同账户同规则期MAX消耗) × 比例(确)
  客情 = 全部有效消耗 × 比例(确)；90天 = 计提有效期，仍逐月计提(确)
  兑现：后付余额抵扣(选月、该月应付须够)(确) / 预付余额抵扣(审批通过直接充余额)(确) / 现金打款 → 付款中心(确)

[渠道统计金额]
  系统能抓 → 直接用，不开放上传(确)
  抓不到 → 选结算期 → 上传标准模板 → 整批审批(确)
       → 通过：匹配行入账，异常行抛错不入账(确)；整批替换同渠道同结算期旧数据(确)

[付款]  录入应付 → 汇出金额 → 打款凭证 → 确认汇出 = 完成(确)

[利润/提成]
  毛利 = 消耗+服务费+税费−客情−返点−手续费−渠道统计金额(确)，按日汇率折人民币(确)
  提成：销售/优化师各自规则，基数(毛利/不含税服务费) 当月汇总落存量阶梯(确)，只展示(确)
  算完 = 渠道付完 + 客情返点结完 + 客户收完(确)；账户×月，计算中/已算完自动判断，数变了自动退回(确 D-00-63～66)
```
